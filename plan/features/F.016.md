# F.016 — Context Profile: Quick Preferences

**Tier 2** · Owner: **P4** · Reviewer: P1 · Status: Not started

## What
Layer 2 of the Child Context Profile — tap-only, ~30 seconds, everything
skippable. These fill the slots that make every line personal.

| Field | Input | Feeds |
|---|---|---|
| Favourite colour | swatches | UI accent, reward motif, Game 1 colour targets |
| Favourite animal | icon picker | movement prompts — *"hop like a rabbit!"* |
| Favourite food | icon picker | category prompts — *"find something you eat"* |
| Favourite place at home | text or tap | where sessions are suggested |
| Favourite sound | short list | success chime, session-start cue |
| Motivating movement | jump/spin/stomp/clap/splash | movement-break content |

## Depends on / Blocks
Depends on F.001, F.005. Blocks F.017 partly.

## Done when
- Tap-only, no typing required (§6.2). All skippable, all editable later.
- Values reach the slot system and visibly change the app — change the
  favourite colour, the accent and reward framing change.
- Empty profile still renders a coherent neutral theme.
- After 10 sessions, one caregiver question: *"Is {companion} still the
  favourite?"* — change or keep, one tap (§6.5).

## Review checklist
- [ ] Can you complete this with taps only, no keyboard?
- [ ] Change favourite colour — does the app visibly change?
- [ ] Does an all-skipped profile break anything?
- [ ] Is everything editable from one settings screen, with no re-onboarding?
- [ ] Does adding these keep total onboarding under two minutes? Time it (§6.6).

## Not in this file
Companion capture (F.004). Avoid list (F.018). People and routine anchors —
Tier 3/4.
