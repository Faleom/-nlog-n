# F.019 — Caregiver Dashboard (Minimal)

**Tier 2** · Owner: **P4** · Reviewer: P1 · Status: Implemented, self-verified — needs fresh-context review

## What
Session recap, focus-stretch trend, generalization list. Minimal — the Tier 2
version, not the full §7.9 spec.

## Depends on / Blocks
Depends on F.010, F.011, F.013. Blocks nothing.

## Done when
- **Recap** in plain language: *"12 minutes, 3 activities, 2 movement breaks.
  Longest focus stretch: 4 minutes."*
- **Focus-stretch trend** — longest sustained attention per session over time.
  The metric ADHD caregivers care about most, and a measurable unit of impact.
- **Generalization list** — which skills reached independence, in which
  contexts. No competitor can show this, because it needs the child's real
  environment (§7.9).
- **Adherence-aware framing**: never rewards streaks or total time. **Shortening
  sessions is shown as progress, not decline** (§7.9).
- **Permanent banner**: *"This is an activity log, not a clinical assessment."*
  Always visible, not first-run only.
- Every number is a plain observation — minutes, counts, tier names. No index,
  no composite, no percentile.
- Populated from **real logged sessions**, not fixtures.
- Phone: accordion, recap open by default (§4.3).

## Review checklist
- [ ] Is the banner permanently visible, or does it scroll away?
- [ ] Any composite score, index, percentile or rating? (§13)
- [ ] Is a shortening session shown as progress?
- [ ] Any streak or total-time reward? There must be none (§7.9).
- [ ] Does it show real logged data, or fixtures?
- [ ] Does any wording judge the child, the parent, or the home? (§13)
- [ ] Does it interpret a trend or surface a concern? It must not — that's how
      the log becomes a screening tool (§10).

## Not in this file
No trend interpretation, no alerts, no "you might want to look into…". No
therapist export (Tier 3+, and only on explicit parent action). No
engagement-by-context (Tier 4).

## Guide refs
§7.9, §10, §13
