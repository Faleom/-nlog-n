# F.002 — Shared Onboarding: Age, Nickname, Two Doors

**Tier 0** · Owner: **P4** · Reviewer: P1 · Status: Implemented, self-verified — needs fresh-context review

## What
The entry every parent sees before the branches split. Age in months (the only
required field), optional nickname, then **two equal doors**.

## Depends on / Blocks
Depends on F.001. Blocks F.003, F.014.

## Done when
- Age in months is the only field required to continue. Nickname skippable.
- **No diagnosis, condition, or developmental question here** (§5.1).
- Two doors, equal visual weight: *"I want activities for my child"* and
  *"I've been thinking about my child's development."* Neither is styled as
  default or as the more serious one.
- A parent can switch branches later with no confirmation and no questions.
- Completes in under 30 seconds.
- 88×88pt touch targets. Portrait on phone.

## Review checklist
- [ ] Any question about diagnosis or development on these screens? (§5.1)
- [ ] Show it to a teammate cold: can they tell which door the app wants them
      to press? If yes, they aren't equal.
- [ ] Can you cross between branches with nothing asked?
- [ ] Does a skipped nickname leave a blank anywhere downstream?
- [ ] Targets ≥88×88pt on a real phone, not in devtools?

## Not in this file
Response profile (F.003). Companion capture (F.004). Any branch content.
